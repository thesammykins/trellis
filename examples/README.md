# Reviewable memory templates

- [AGENTS memory block](AGENTS.memory-block.md): a short project-instruction entry
  pointing to an enabled memory integration.
- [Memory skill](memory-skill/SKILL.md): guidance for focused retrieval and proposed
  updates.

Review and adapt these before installation. They do not grant permissions, install
tools or represent an approved project decision. Use actual app exports and the
current [memory guide](../docs/MEMORY-AND-DREAMING.md) for storage formats.
