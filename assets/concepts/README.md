# Original concept images

These PNGs are generated visual explorations, retained as design references.

| File | Role |
| --- | --- |
| 02-trellis-dark-primary.png | Proposed primary composition: project list, real terminal area, session strip, contextual memory inspector |
| 01-hearth-light-exploration.png | Earlier light-appearance exploration, retained for provenance and material contrast |

These are visual references, not screenshots of working software. The names, dates, output, icons and statuses shown are illustrative. Trellis is the provisional name adopted in the written packet; Hearth is not a second application.

Use a single semantic light/dark design system. Do not clone two incompatible sets of controls. The written DESIGN.md, actual Apple controls, accessibility and real agent rendering take precedence over decorative image details.

The other screens are specified in DESIGN.md. These concept images do not include Apple font files, third-party icon packs or terminal binaries.
