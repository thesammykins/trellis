# Trellis app icon

`TrellisIcon.svg` is a native vector source for future macOS icon packaging. Its terminal prompt becomes a growing stem, held by a quiet trellis grid. The near-black field matches the terminal-led dark concept; the mint and teal accents stay legible against the light exploration without turning the mark into a second visual system.

The mark uses a 1024-point rounded-square canvas and wide, simple strokes so its prompt and leaves remain distinct at 32 pixels. It contains no embedded raster artwork, fonts or external resources.
